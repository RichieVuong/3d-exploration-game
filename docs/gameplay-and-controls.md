# Gameplay and Controls

The objective is to explore each area, collect all available energy shards, activate checkpoints, and reach the exit beacon. The game uses short objectives and visible feedback so the player always knows what to do next.

| Input | Action |
|---|---|
| W / Up | Move forward |
| S / Down | Move backward |
| A / Left | Move left |
| D / Right | Move right |
| Space | Jump |
| Esc | Release the mouse |

The three-area structure is designed to introduce movement first, then add hazards and longer routes as the player progresses.
